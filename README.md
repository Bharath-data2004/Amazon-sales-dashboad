# 🛒 Amazon Sales Dashboard – Power BI

## 📌 Project Overview

The **Amazon Sales Dashboard** is an interactive Power BI dashboard designed to analyze and visualize Amazon sales performance. The project transforms raw sales data into meaningful business insights using **Power BI, Power Query, DAX, and interactive visualizations**.

The dashboard provides a clear overview of sales performance, product trends, customer behavior, and order-related metrics, helping users understand key business performance indicators.

## 🎯 Objectives

- Analyze overall Amazon sales performance.
- Track total sales, orders, and product performance.
- Identify top-performing products and categories.
- Analyze sales trends over time.
- Understand customer and regional sales patterns.
- Monitor key performance indicators (KPIs).
- Create an interactive and user-friendly business dashboard.

## 📊 Dashboard Features

### Key Performance Indicators
- 💰 Total Sales
- 📦 Total Orders
- 🛍️ Total Products
- 📈 Average Order Value
- 👥 Customer/Sales Analysis

### Sales Analysis
- Sales by month and year
- Sales by product category
- Sales by region
- Top-selling products
- Product performance comparison

### Interactive Features
- Date filters
- Category filters
- Region filters
- Product-level analysis
- Interactive charts and slicers
- Drill-down and cross-filtering

## 🛠️ Tools & Technologies

- **Power BI**
- **Power Query**

- **Data Visualization**
- **Data Cleaning & Transformation**

## 🔄 Project Workflow

1. Imported the Amazon sales dataset into Power BI.
2. Cleaned and transformed the data using **Power Query**.
3. Handled missing values and corrected data types.
4. Created calculated columns and measures using **DAX**.
5. Built relationships between relevant tables.
6. Created KPIs and analytical visuals.
7. Added slicers and interactive filters.
8. Designed the final Amazon Sales Dashboard.
9. Analyzed the dashboard to identify important sales trends and insights.

## 📈 Business Insights

The dashboard can be used to identify:

- Which products generate the highest sales.
- Which categories perform best.
- Monthly and yearly sales trends.
- High-performing and low-performing products.
- Regional sales performance.
- Changes in sales and order volume over time.
- Areas where sales performance can be improved.
